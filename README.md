## Recipe Recommendation System
An AI-powered Recipe Recommendation Web Application built using Python and Streamlit that recommends recipes based on ingredients and user preferences using NLP techniques.

## Live Demo
🌐 https://your-app-name.streamlit.app

##  Project Overview
This project uses Natural Language Processing (NLP) and Machine Learning techniques to recommend recipes intelligently.  
The recommendation engine uses TF-IDF Vectorization and Cosine Similarity to find similar recipes based on ingredients and recipe content.

The application allows users to:
- Search recipes
- Get smart recommendations
- Save favorite recipes
- Rate recipes
- Explore recipe details interactively

## Features

## Installation & Setup
1.Clone Repository
  git clone https://github.com/teja478/Recipe-Recommendation-App.git
2.Navigate to Project Folder
  cd Recipe-Recommendation-App
3.Install Dependencies
  pip install -r requirements.txt
4.Run Application
  streamlit run app.py
