# Recipe-Recommendation-App
A smart and interactive Recipe Recommendation Web Application developed using Python, Streamlit, Machine Learning, and NLP techniques.  
This application helps users discover recipes based on ingredients, preferences, and recipe similarity in a simple and user-friendly way.
The project uses Natural Language Processing (NLP) and TF-IDF Vectorization to understand recipe data and recommend similar dishes instantly.

## Features

- Search recipes easily
- Get recipe recommendations instantly
- AI & NLP based recommendation system
- Recipe ratings support
- Save favorite recipes
- Random recipe suggestions
- Clean and interactive Streamlit UI
- Fast and lightweight application

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- NLP (Natural Language Processing)
- TF-IDF Vectorizer
- Cosine Similarity
- JSON
- HTML & CSS
